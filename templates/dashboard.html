Threshold Analysis
How threshold 0.42 was selected
Optimal = 0.42
The default threshold of 0.50 yielded ~50% recall on Class 1. By evaluating recall and accuracy across thresholds 0.30–0.70, we found 0.42 maximises Class 1 recall (75%) while keeping overall accuracy stable at ~60%. This threshold was chosen because in clinical settings, missing a high-risk patient (false negative) is more dangerous than a false alarm (false positive).

Engineered Features
Five derived features added to boost predictive signal
total_visits
n_inpatient + n_outpatient + n_emergency. Summarises total prior healthcare utilisation in a single feature.
visit_severity
3×inpatient + 2×emergency + 1×outpatient. Weights visits by clinical severity — inpatient stays carry the highest risk signal.
polypharmacy
Binary flag: 1 if medications ≥ 5. Polypharmacy is a well-established clinical readmission risk factor.
meds_per_day
n_medications ÷ time_in_hospital. Captures medication intensity relative to stay duration.
long_stay
Binary flag: 1 if time_in_hospital > 7 days. Extended stays correlate strongly with condition severity and readmission.
